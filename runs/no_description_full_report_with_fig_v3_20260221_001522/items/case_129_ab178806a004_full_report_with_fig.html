语言特征

韩国语特征：

  • 98.9%的片段包含韩文字符（가-힣）
  • 使用正式和非正式敬语混合

数据预处理建议

推荐流程：

1. 文本清洗：

移除纯标点符号片段（1-2字符）

标准化引号和标点符号

去除空白字符

2. 分段处理：

将超长段落（300字符）拆分

合并过短段落（10字符）

保持段落完整性

3. 标记化：

使用韩国语分词器（如KoNLPy、MeCab）

提取名词、动词、形容词

识别命名实体

4. 特征提取：

词频-逆文档频率（TF-IDF）

词嵌入（Word2Vec、FastText）

句子嵌入（Sentence-BERT）
