Model Architecture

The Kimi K2.5 architecture introduces several innovations:

1. MoonViT-3D Vision Encoder

  • Native-Resolution Support: Processes images up to 3840x2160 without resizing or distortion
  • NaViT Patch Packing: Enables variable resolution support without compromising efficiency
  • 3D Temporal Compression: Reduces 4-frame video to temporal average, optimizing memory usage

2. Token Architecture

The model uses a sophisticated token mixing strategy:

  • Constant 10:90 Ratio: Vision tokens are maintained at 10% of total tokens throughout training
  • Vision Tokens: Generated at 10% ratio from encoded images
  • Text Tokens: Represent 90% of the token stream, maintaining text-dominant processing

3. Agent Swarm Framework

A novel orchestration mechanism for agentic tasks:

  • Trainable Orchestrator: Learns when and how to create sub-agents dynamically
  • Custom System Prompts: Each sub-agent receives task-specific instructions
  • Parallel Execution: Reduces latency by 4.5x compared to sequential processing
