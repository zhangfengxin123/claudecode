执行摘要

本报告基于3171家A股上市公司2025年度业绩预告数据，全面分析了中国资本市场的盈利前景和行业趋势。分析显示，约51.3%的公司预计盈利，45.7%预计亏损，呈现出分化明显的市场格局。传统能源和资源类公司表现强劲，而房地产、光伏等行业面临较大压力。本报告通过多维度数据可视化，为投资者提供决策参考。

关键发现

1. 预增公司占比最高: 642家公司（20.3%）预计业绩预增，显示市场仍有大量成长性公司

2. 首亏公司数量可观: 482家公司（15.2%）首次亏损，需警惕行业下行风险

3. 扭亏公司数量显著: 373家公司实现扭亏，体现了部分公司的经营改善能力

4. 增亏与减亏并存: 369家公司增亏，481家公司减亏，显示经营分化明显

预警类型解读

  • 预增/略增: 业绩预计增长，公司经营状况良好
  • 预减/略减: 业绩预计下滑，需关注原因
  • 扭亏: 从亏损转为盈利，经营能力提升
  • 首亏: 从盈利转为亏损，经营恶化
  • 增亏: 亏损幅度扩大，经营压力加剧
  • 减亏: 亏损幅度收窄，经营有所改善
  • 续亏: 持续亏损，经营困难
