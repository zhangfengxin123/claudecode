福利刚性视角下财政福利支出对居民消费的影响研究

执行摘要

本研究基于中国31个省市2000-2019年的面板数据，从福利刚性视角深入分析了财政福利支出对居民消费的影响机制。研究发现，财政福利支出对居民消费水平和消费结构升级均具有显著的正向促进效应，但这一影响存在明显的非线性特征和异质性影响。

核心发现

  • 财政福利支出对居民消费存在显著正向影响，且影响效应随消费水平提升而增强
  • 福利刚性在财政福利支出与居民消费之间扮演重要中介角色
  • 存在明显的城乡差异和区域异质性
  • 快速增长的财政福利支出可能陷入"福利陷阱"风险

1. 财政福利支出发展趋势分析

1.1 总体趋势

2000-2019年间，中国财政福利支出占GDP比重呈现稳步上升趋势，从2000年的2.17%增长至2019年的8.08%，增长了近4倍。这一趋势表明我国财政支出结构正向社会福利领域倾斜，纯投资性支出占比下降。

1.2 区域差异分析

东中西部地区财政福利支出占GDP比重存在明显差异，呈现"西部中部东部"的格局。

区域特征

  • 西部地区：财政福利支出占GDP比重最高，2019年达到9.2%
  • 中部地区：处于中间水平，2019年为8.6%
  • 东部地区：相对较低，但增长最为稳定，2019年为6.7%

东部地区虽然占GDP比重相对较低，但由于经济总量大，财政福利总支出和人均财政福利支出均位居全国前列。2019年，受减税降费政策影响，东部地区财政收入增速回落，但教育、医疗、就业等民生性福利支出的刚性特征使得该部分支出无法降低，导致财政福利支出占总财政支出比重一跃成为各地区最高，达到56.10%。

3. 财政福利刚性的中介机制分析

3.1 财政福利刚性测算与演变

财政福利刚性是指财政福利支出"只升不降"的特性，即使在财政吃紧的情况下也无法降低。

3.1.1 全国财政福利刚性演变趋势

2002-2019年间，全国财政福利刚性系数整体呈现波动上升趋势：

  • 2002-2009年：从0.06缓慢增长至0.17
  • 2010-2014年：快速上升至0.28
  • 2015-2019年：在0.33-0.36区间波动

3.1.2 区域差异

各省市财政福利刚性存在显著差异：

  • 低刚性地区：江苏省（0.05）、天津市（0.11）
  • 高刚性地区：贵州省（0.25）、重庆市（0.25）、广东省（0.24）
  • 中部地区：湖南（0.48，峰值最高）、河南（0.22）、湖北（0.20）

研究发现，一些较为偏远、地域发展不占优势的地区相对刚性较高，这可能与这些地区对中央财政转移支付的依赖度较高有关。

3.2 中介效应检验

3.2.1 全体居民消费水平的中介效应

采用分位数中介效应模型检验财政福利支出通过福利刚性对全体居民消费水平的影响机制。

检验结果

  • 第一步：人均财政福利支出对全体居民消费水平的总效应显著为正
  • 第二步：人均财政福利支出对财政福利刚性影响显著为正
  • 第三步：人均财政福利支出和财政福利刚性对消费水平的影响均显著

这表明财政福利支出不仅直接影响居民消费水平，而且通过推动福利刚性增强间接影响消费水平，存在显著的部分中介效应。

4. 深层机理分析

4.1 福利刚性的双重效应

财政福利刚性在财政福利支出与居民消费关系中扮演着复杂的中介角色：

正向效应

  • 提供稳定的社会保障预期，降低预防性储蓄
  • 增强居民消费信心，促进消费结构升级
  • 在中高消费群体中，福利刚性通过稳定预期促进消费

负向效应

  • 挤压其他公共支出，可能影响公共服务质量
  • 在低消费群体中，刚性支出可能导致资源配置效率低下
  • 财政压力增大时，可能通过其他税种转嫁给居民

4.2 门槛效应的经济学解释

城镇化水平的门槛效应反映了制度环境对财政福利支出效果的重要影响：

  • 低城镇化阶段：制度不完善，财政福利支出的溢出效应有限
  • 中城镇化阶段：制度逐步完善，人口集聚效应显现，财政福利支出效果最佳
  • 高城镇化阶段：边际效应递减，但仍保持正向影响

4.3 区域异质性的成因

东中西部地区的差异主要源于：

1. 经济发展水平：东部地区经济基础好，财政可持续性强

2. 人口结构：西部地区人口流出，老龄化问题相对突出

3. 政策导向：国家区域发展战略导致的资源配置差异

4. 财政体制：转移支付依赖程度的不同

5. 政策建议

5.1 优化财政福利支出结构

  • 建立动态调整机制：根据经济发展阶段和人口结构变化，适时调整财政福利支出规模和结构
  • 提高支出效率：加强对财政福利支出的绩效评估，提高资源配置效率
  • 差异化配置：根据各地区实际情况，实施差异化的财政福利政策

5.2 缓解福利刚性约束

  • 增强支出弹性：在保障基本民生的前提下，适当引入支出弹性机制
  • 多元化融资渠道：鼓励社会资本参与社会福利服务供给
  • 建立预警机制：对财政福利刚性水平进行监控，防范财政风险

5.3 促进城乡协调发展

  • 加大对农村地区的投入：提高农村居民消费能力，缩小城乡消费差距
  • 完善农村社会保障体系：增强农村居民的消费信心
  • 推进新型城镇化：发挥城镇化对消费结构升级的促进作用

5.4 深化财税体制改革

  • 优化税收结构：减少对消费的过度征税，增强所得税的调节功能
  • 完善转移支付制度：提高转移支付的精准性和效率
  • 建立跨周期调节机制：在经济下行期加大对消费的支持力度

6. 研究结论

本研究通过实证分析得出以下主要结论：

1. 财政福利支出对居民消费具有显著促进作用，且存在明显的非线性特征，影响效应随消费水平提升而增强。

2. 福利刚性是重要的中介机制，财政福利支出通过推动福利刚性增强间接影响居民消费，这一机制在不同消费水平和城乡之间存在异质性。

3. 存在明显的门槛效应，城镇化水平在64%和68%处存在双重门槛，财政福利支出对消费结构升级的影响在不同门槛区间呈现差异化特征。

4. 区域异质性显著，东中西部地区在财政福利支出规模、刚性和消费影响机制上均存在差异。

5. 面临"福利陷阱"风险，财政福利支出的快速增长和刚性约束可能导致财政可持续性压力，需要建立动态调整机制。

7. 研究展望

未来研究可以在以下方面进一步深入：

1. 引入更多维度的控制变量：如收入分配、社会保障水平、金融市场发展等

2. 拓展研究时间跨度：纳入更长时间序列数据，观察长期趋势

3. 深化机制研究：进一步探讨福利刚性影响消费的具体渠道

4. 国际比较研究：与其他国家的财政福利政策进行比较分析
