执行摘要

基于UBS 2026年大中华区会议的深入调研，本报告分析了中国银行业和房地产行业的2026年展望。核心发现显示，虽然最艰难的时期可能已经过去，但复苏之路仍然充满挑战。

关键结论

  • 宏观经济：2026年GDP增长目标预期为4.5-5.0%，通胀压力略有缓解，但房地产拖累持续
  • 银行业：净息差压力减轻，手续费收入回升，推荐高股息率的四大国有银行
  • 房地产：价格下跌趋势持续（2026年再跌10%），政策支持有限，整体保持谨慎态度
  • LGFV债务：化解进展顺利，债务增速放缓，风险得到有效控制

一、宏观经济展望：边际改善但挑战犹存

1.1 GDP增长目标与通胀预期

economic_indicators_comparison.json
asset

根据UBS经济学家预测，2026年中国实际GDP增长率预期为4.5%，略低于市场预期的"接近5%"水平。这一增长目标的设定基于以下考量：

  • 长期发展目标：为实现2035年长期经济发展目标，中国需要在未来10年保持平均4.2%的实际GDP增长
  • 出口表现：强劲的出口动能和欧洲重新军事化的需求为经济增长提供支撑
  • 房地产拖累：房地产部门对GDP的拖累效应相比2025年有所缓解

通胀指标

  • CPI：从2025年的0.2%上升至2026年的0.5%
  • PPI：降幅从2025年的-2.5%收窄至2026年的-0.5%
  • GDP平减指数：负增长幅度收窄，名义GDP增长改善

1.2 政策展望：有限刺激，精准发力

货币政策

  • 预期降息10个基点（bps），比2025年更为积极
  • 银行净息差（NIM）成为降息的关键约束因素
  • 30年期国债收益率风险偏向上行

财政政策

  • 保持必要水平的财政支持，而非进一步大幅扩张
  • 政策重点转向"提高质量和效率"而非简单规模扩张
  • 以旧换新补贴政策的刺激效果有限，可能逐步退出

二、银行业分析：息差压力缓解，基本面改善

2.1 净息差（NIM）：降幅收窄至个位数

银行业面临的核心挑战是净息差压力，但2026年这一压力将显著缓解：

  • 2025年：银行业NIM同比下降11个基点
  • 2026年预期：NIM降幅收窄至约6个基点

改善因素

1. 负债端：2022-2023年发行的高息存款将在2026年到期，存款成本下降

2. 资产端：LPR降息（2025年5月降息10bps）的影响已部分消化

3. 定价机制：行业自律机制防止价格竞争过度加剧

2.2 收入结构：多元化复苏

利息收入（NII）

  • 贷款定价在2026年初基本保持稳定
  • 企业贷款需求相对稳健
  • 零售贷款需求仍然疲软

手续费收入

  • 费率下调压力缓解，大部分费率下调已在2025年完成
  • 业务量回升，特别是保险和理财产品销售
  • 以旧换新补贴政策的到期释放客户资金用于其他投资

投资收益

  • 预期表现不佳，受债券市场不利影响
  • 2025年高基数效应带来挑战
  • 银行普遍持有大量未实现收益

2.3 资产质量：总体可控，局部承压

贷款质量趋势

贷款类型资产质量状况风险评估
房地产开发商贷款NPL率较高（5.35%）需要关注个别开发商如万科的降级风险
住房抵押贷款NPL率相对较低LTV水平健康（40-50%），风险可控
中小企业贷款持续承压银行在扩张此类贷款时保持谨慎
消费贷款压力显现高利率消费贷款（20%）面临监管收紧
政府相关贷款资产质量改善NPL率接近0%

关键洞察：

  • 银行对房地产开发商的贷款仍有50%以上被分类为正常，监管的容忍政策延缓了NPL的确认
  • 抵押品价值在房价下跌城市面临风险，但银行退出机制（如以折扣方式出售给AMC）可能需要很长时间

2.5 银行业影响传导机制

影响路径分析

1. 政策利率降息→ 净息差下降（11bps → 6bps）→ 利息收入降幅收窄

2. 高息存款到期→ 存款成本下降 → 利息收入改善

3. 房地产风险持续→ 资产质量压力 → 信用成本上升

4. 费率影响消退+ 业务量回升→ 手续费收入增长

5. 债市不利+ 高基数效应→ 投资收益滞后

三、房地产市场：下行压力持续，政策支持有限

3.1 市场展望：持续疲软但降幅收窄

2026年预测

  • 房地产价格：预计继续下跌10%，全年下跌5-6%（建筑面积/价值）
  • 房地产投资：降幅从2025年的-17.2%收窄至-10%
  • 房地产销售：全国销售额下跌5-6%

价格底部难觅的原因

1. 租金收益率：仍未显著改善，租金下降导致租金收益率仍远低于抵押贷款利率

2. 保障性住房：2026年和2027年保障性住房完工量增加

3. 收入预期：消费者收入预期尚未恢复

价格下行空间

  • 如果租金收益率与抵押贷款利率匹配，房价可能从当前水平再下跌30-40%
  • 租房趋势取代购房趋势，市场结构发生根本性变化

3.2 政策预期：大规模刺激概率低

专家普遍认为2026年推出重大新政策的可能性较小：

不太可能的政策

  • 中央政府大规模购买库存
  • 对现有抵押贷款的大规模财政补贴

可能的政策

  • 进一步减少交易限制性政策
  • 求是杂志文章被视为提振市场信心的宣传性文章，而非新的中央政府立场

抵押贷款利率补贴的障碍

1. 财政支出来源问题（中央政府 vs 地方政府）

2. 补贴期限问题

3.4 房地产市场风险传导

风险传导链条

1. 房价下跌→ 开发商销售压力、银行抵押物价值下降、购房者观望情绪增强

2. 投资下滑→ 开发商新开工减少、银行对公贷款需求下降

3. 信心不足→ 购房者转向租房市场

4. 开发商贷款NPL率较高→ 银行体系资产质量压力

5. 抵押贷款NPL率相对较低→ 银行体系风险可控

3.5 市场分化：结构性机会存在

尽管整体前景悲观，但存在结构性机会：

豪华住宅

  • 需求仍然存在，进入门槛较高
  • 成都C&D海玉项目：土地成本41,200元/平方米，售价超过77,000元/平方米
  • 首批推出82套，售出62套（去化率约76%），475平方米大户型最受欢迎

优质购物中心

  • 成都万象城（MixC）：2025年零售额约85亿元人民币，位列成都第二
  • 积极的租户调整（2025年35%的租户更换），引入更多运动和生活方式品牌
  • 预期五年内零售额可达100亿元人民币

四、LGFV债务化解：进展显著，风险可控

4.1 债务增速放缓

LGFV（地方政府融资平台）债务增长已大幅放缓：

  • 2022-2023年：增速10-15%
  • 2025年上半年：增速降至约5%
  • 2026年预期：进一步下降

四川省案例

  • 银行贷款：70%
  • 债券：20%
  • 非标信贷资产：10%

  • 2025年债券平均风险利差比2024年低约60个基点
  • 比2022年水平低260个基点
  • LGFV新发行债券收益率普遍低于4%

4.3 债务化解机制

化解机制

1. 债务置换：

基于2024年宣布的12万亿元化解计划

截至2025年底，已发行5.6万亿元地方政府债券用于化解隐性债务

2. 商业化转型：

LGFV转型为商业化、市场化运作的国有企业

每个城市和行政区（省/地级市/县）只允许保留一家LGFV

所有LGFV应在2027年上半年前完成转型

风险控制

  • 目前无公开LGFV债务违约
  • 有效的省级协调促进债务化解
  • 财政部认可的14万亿元债务互换计划的LGFV正在进行重组

4.4 银行视角：成都银行（BOCD）案例

成都银行的表现

  • 自2021年以来，贷款和存款余额增长最快
  • 存款市场份额排名第2，贷款市场份额排名第4

政府相关贷款

  • 是成都银行贷款增长的主要驱动因素
  • "成渝经济圈"政府主导投资相对强劲
  • 不同地区贷款定价呈下降趋势，差异较大

隐性债务化解

  • 预期2027年6月前完成相关隐性债务的完全化解
  • 主要通过：

2. LGFV转型为商业化、市场化运作的实体

房地产相关风险敞口

  • 房地产开发商贷款 + 零售住房抵押贷款约1300亿元人民币
  • 约占贷款总额的15%
  • 抵押贷款占大多数
  • 开发商贷款风险有限，已提前退出对风险开发商的贷款，主要向国有开发商放贷

5.2 私营企业：技术创新为核心竞争力

调研的私营企业涉及三个领域：

1. 生物技术：干细胞和CAR-T疗法的研究和商业化

2. 人工智能：为金融机构和零售投资者提供AI解决方案基础设施

3. 公共服务：智能停车场运营，最终实现无人停车和停车场维护

共同特点

  • 技术作为核心竞争力
  • 传统行业必须拥抱技术升级，以避免在当前竞争环境下的不可持续利润率收缩
  • 技术创新企业享受政策支持

出海挑战

  • 跨境数据传输是AI公司的关键风险领域
  • 地缘政治和数据安全风险
  • 市场差异（例如，在中东支付停车费不是常态）

七、结论

UBS 2026年大中华区会议揭示了一个核心主题：虽然最艰难的时期可能已经过去，但中国银行业和房地产行业的复苏之路仍然充满挑战。

关键要点

1. 边际改善：宏观经济指标呈现边际改善，通胀压力缓解，但可持续性仍有待观察

2. 银行业韧性：银行业基本面改善，净息差压力缓解，但需要关注资产质量风险

3. 房地产困境：房地产市场下行压力持续，政策支持有限，价格底部难以确定

4. 债务化解：LGFV债务化解进展顺利，风险得到有效控制

5. 结构性机会：在整体谨慎的背景下，仍存在结构性投资机会

政策传导机制

展望2026年，投资者应采取防御性与结构性增长相结合的策略，关注高股息率银行和具备核心竞争力的房地产细分领域，同时密切关注宏观经济政策和市场信心的变化。
