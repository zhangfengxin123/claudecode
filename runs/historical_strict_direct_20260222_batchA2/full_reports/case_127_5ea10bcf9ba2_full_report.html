执行摘要

根据UBS最新的中国宏观与行业展望报告，2026年中国经济将在政策支持下实现4.5-5.0%的GDP增长，但房地产下行风险仍然严峻，预计价格将进一步下跌10%，潜在下行空间达30-40%。在此背景下，银行业成为相对安全的投资选择，优选股票提供约5.5%的股息收益率，NIM压力逐步缓解。

一、宏观经济展望

1.1 关键指标预测

2026年中国宏观经济将在政策支持下保持稳健增长，政府GDP目标设定为4.5-5.0%，UBS预测实际增长率为4.5%。通胀压力仍然较低，CPI预计为0.5%，PPI处于-1%至0%区间，为货币政策提供了操作空间。

关键观察：

  • 低通胀环境：CPI和PPI的低水平为央行进一步降息提供了空间
  • 结构性转型：房地产投资持续下降-5%至-10%，经济正在向消费和服务业转型
  • 政策支持：3000亿元换购补贴政策将推动零售销售增长至3.7%

1.2 政策驱动机制

政策传导路径：

1. 货币政策：10bps降息 → 降低融资成本 → 刺激投资和消费

2. 财政政策：换购补贴3000亿元 → 提振零售销售 → 支持GDP增长

3. LGFV债务支持：债务置换 → 降低违约风险 → 稳定金融系统

二、房地产下行风险分析

2.1 价格走势预测

房地产市场面临持续下行压力，UBS预测2026年房价将进一步下跌10%，2027年再跌5%，累计跌幅达15%。更悲观情景下，潜在下行空间高达30-40%。

价格下行驱动因素：

  • 供需失衡：销售量持续下滑5-6%，库存高企
  • 购房者信心低迷：预期价格继续下跌，观望情绪浓厚
  • 融资环境收紧：开发商融资困难，债务风险高企
  • 政策限制：限购、限贷等措施仍在部分城市实施

  • 资产减值压力：银行需计提更多拨备，但整体可控

  • 银行风险管理能力提升：AMC处置不良资产的能力增强

5.1 换购补贴政策效应

政策影响分析：

  • 2024年零售销售增长：3.5%无政策支持
  • 2025年零售销售增长：3.7%换购补贴3000亿元
  • 增量贡献：0.2个百分点，约2000亿元消费增量

政策传导机制：

1. 消费者以旧换新 → 获得补贴

2. 刺激耐用品消费 → 家电、汽车、家具

3. 带动产业链 → 制造业、服务业

4. 最终支持GDP增长

八、结论与展望

8.1 核心结论

1. 宏观经济稳健：GDP增长4.5%，政策支持力度充足

2. 房地产风险可控但需警惕：10%下跌可接受，30-40%为极端情景

3. 银行业迎来拐点：NIM压力缓解，股息收益率具吸引力

4. LGFV风险下降：利差大幅收窄，债务置换效果显著

5. 人民币温和升值：汇率在合理区间波动

8.2 2027年展望

基于当前分析，我们对2027年经济展望如下：

  • GDP增长：4.0-4.5%房地产拖累减弱
  • 房地产：价格企稳，可能小幅回升0-5%
  • 银行业：NIM回升，ROE改善，股息率保持5%+
  • 人民币汇率：6.5-7.0区间双向波动
  • 出口：增长3-4%，保持竞争力
