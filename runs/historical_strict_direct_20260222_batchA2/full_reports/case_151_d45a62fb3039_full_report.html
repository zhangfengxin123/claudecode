一、执行摘要

本报告基于九江市2024年区域研究报告和德安县城市发展有限公司2025年信用评级报告，对九江市区域经济、财政状况以及德安县重点城投平台进行全面分析。

核心发现：

九江市层面：

  • 经济总量持续增长，2022年GDP达到4026.60亿元，稳居江西省前三位
  • 产业结构以工业为主导，五大主导产业优势明显，新兴产业占比持续提升
  • 财政实力较强，但依赖上级补助程度较高
  • 区域债务规模持续增长，广义债务率282.18%，压力适中
  • 城投债券融资渠道畅通，3年期存续债利差持续收窄

德安县层面：

  • 经济基础良好，2024年一般公共预算收入15.08亿元
  • 德安城发作为重要基础设施建设主体，主体信用等级AA，展望稳定
  • 债项信用等级AAA，由省级担保机构提供强担保
  • 面临短期偿债压力和资本支出压力，但整体风险可控

投资建议：

  • 九江市整体信用状况良好，经济财政基础扎实，适合中长期投资
  • 德安城发信用评级较高，省级担保增信作用显著，债券投资风险较低
  • 建议关注九江市区县差异化发展带来的结构性机会

二、九江市区域经济分析

2.1 区位优势与交通基础设施

九江市地处赣、鄂、湘、皖四省交界处，具有突出的区位优势：

交通基础设施完善：

  • 港口运输：九江港拥有11个港区，2023年上半年货物吞吐量9168万吨，同比增长13.6%，在全国36个主要内河港口中位居第7位
  • 铁路运输：已建成昌九城际铁路等多条国铁Ⅰ级铁路，昌九高速铁路正在建设中
  • 航空运输：九江庐山机场复航后旅客吞吐量快速增长，2023年达到29.13万人次，位居江西省前5位

2.2 经济增长与产业结构

2.3 产业体系分析

九江市已形成以五大主导产业为主、五大新兴产业为辅的产业格局：

五大主导产业：

1. 石油化工：九江石化是江西唯一石油加工企业，2022年实现利税总额259.90亿元，贡献了江西省超过70%的油品

2. 钢铁有色冶金：九江萍钢钢铁有限公司等重点企业支撑产业发展

3. 现代轻纺：赛得利作为我国最大的纤维素纤维生产企业，产业优势明显

4. 装备制造：产业集群逐步形成

5. 电力新能源：英利能源等企业发展良好

五大新兴产业：

1. 新材料：晨光新材料等企业发展迅速

2. 智能电器：智能化制造水平不断提升

3. 绿色食品：中粮粮油等企业布局良好

4. 生物医药：产业基础逐步夯实

5. 电子信息：德福科技等企业发展迅速

龙头企业优势：

  • 九江石化：2022年实现营业收入512.6亿元，上交税费超过130亿元
  • 星火有机硅：我国最大的有机硅生产企业
  • 赛得利：我国最大的纤维素纤维生产企业
  • 天赐材料：锂电池电解液国内市场占有率超35%

产业产值结构变化：

2018-2022年，九江市五大传统工业总产值占36个工业行业总产值的比重稳定在48.50%-52.50%，其中：

  • "计算机、通信和其他电子设备制造业"比重由2018年2.09%增至2022年9.06%
  • "石油、煤炭及其他燃料加工业"比重由8.35%降至0.18%
  • "纺织业和纺织服装、服饰业"比重由14.61%降至8.78%

这表明九江市产业结构正在向高技术、高附加值方向转型。

2.4 批发零售业与金融业

批发零售业：

  • 2018-2022年年均复合增长率为9.70%
  • 2022年销售额占全省比重为10.28%，仅次于南昌市和赣州市
  • 2022年规模以上工业企业利润总额704.40亿元，位居省内首位
  • 未来增速有望提升，主要受益于交通基础设施持续建设

金融业：

  • 金融机构贷款余额持续增长
  • 九江银行作为江西省第二大城市商业银行，资产规模4928.66亿元
  • 2018-2022年不良贷款率波动增长，截至2022年底增至1.82%，但仍处于可控范围

三、九江市财政状况分析

3.1 财政收入结构

一般公共预算收入：

  • 2018-2023年年均复合增长率3.77%
  • 财政自给率维持在42.00%-48.50%区间
  • 对上级补助收入依赖程度较高

政府性基金收入：

  • 2018-2023年波动幅度较大
  • 2022-2023年受房地产行业下行影响明显下降
  • 2022-2023年住宅类用地出让面积分别为325.72万平方米和214.41万平方米

3.2 税收收入分析

税收构成：

  • 增税收入2022年降幅较大，主要受纾困政策影响
  • 企业所得税2023年较2022年下降24.81%，主要受税收优惠政策影响

税收优惠政策：

  • 制造业中小微企业延缓缴纳2022年第一、二季度部分税费
  • 增值税小规模纳税人适用3%征收率的应税销售收入免征增值税
  • 增值税留抵退税政策范围扩大至小微企业等

中部：

  • 主要区县：浔阳区、濂溪区、柴桑区

六、九江市城投公司分析

6.1 城投公司概况

股权结构：

  • 九江市国有投资控股集团有限公司（九江国控）为市级主要城投平台
  • 通过九江城发间接控股主要市级城投公司和部分区县级城投公司
  • 股权集中度很高

资产规模：

截至2023年9月底，九江国控资产规模2512.16亿元，在江西省位居前列。

6.2 经营性业务

九江国控依托地理位置和自然资源优势积极拓展经营性业务：

  • 贸易业务：依托九江港的航运优势开展，上下游企业集中于长江沿线省市
  • 砂石开采业务：享有自2021年起为期30年的砂石资源开采权，业务持续性强

2022年，九江国控的贸易和砂石开采销售收入比重合计47.14%，利润比重合计20.78%。

  • 除濂溪区和彭泽县为2家发债城投外，其余区县均为1家
  • 整体财务杠杆水平适中，非标债务比重一般

短期偿债指标较弱的城投：

  • 柴桑投资：现金短期债务比0.22倍
  • 彭泽城投：现金短期债务比0.25倍
  • 永修城投：现金短期债务比0.33倍
  • 瑞昌投资：现金短期债务比0.40倍
  • 修水城投：现金短期债务比0.14倍

七、风险分析与应对策略

7.1 九江市层面风险

1. 经济增长放缓风险

风险表现：

  • 2022年和2020年GDP增速分别降至4.30%和3.80%
  • 宏观经济波动影响加大

应对策略：

  • 加快产业结构转型升级，提高新兴产业占比
  • 培育新的经济增长点，提升经济韧性
  • 深化与武汉、南昌等省会城市的产业协作

2. 房地产行业下行风险

风险表现：

  • 政府性基金收入2022-2023年明显下降
  • 2024年GDP下降，房地产业影响较大
  • 常住人口净流出4.51%（2012-2022年）

应对策略：

  • 积极推进"保交楼"项目，稳定房地产市场信心
  • 加大契税补贴等政策措施力度
  • 发展绿色建筑和住房租赁市场

3. 债务增长风险

风险表现：

  • 政府债务和城投债务年均复合增速均超过16%
  • 广义债务率282.18%，持续上升

应对策略：

  • 严控新增债务规模，优化债务结构
  • 提高财政资金使用效率，增强偿债能力
  • 推进城投公司市场化转型

7.2 德安县层面风险

1. 短期偿债压力

风险表现：

  • 短期债务占比较高
  • 现金短期债务比0.68倍，流动性压力存在

应对策略：

  • 优化债务期限结构，增加长期债务比重
  • 加强应收账款管理，提高资金回笼效率
  • 合理安排项目投资节奏，匹配资金来源

2. 经营性现金流不确定性

风险表现：

  • 基础设施建设业务回款波动较大
  • 受政府结算进度影响明显

应对策略：

  • 完善项目结算机制，提高回款确定性
  • 拓展经营性业务，增强造血能力
  • 建立现金流预警机制

3. 资本支出压力

风险表现：

  • 在建及拟建项目尚需投资约47.76亿元
  • 资金来源需要合理安排

应对策略：

  • 优先保障重点项目建设
  • 多渠道筹措建设资金
  • 争取上级财政和政策性金融支持

7.3 德安城发风险

1. 营业收入下降风险

风险表现：

  • 2024年营业收入较2022年下降20.8%
  • 主要受子公司划出影响

应对策略：

  • 拓展新的业务领域
  • 提高现有业务盈利能力
  • 争取政府项目支持

2. 资产流动性较弱

风险表现：

  • 存货和应收类款项占比较高
  • 应收账款集中度较高

应对策略：

  • 加强应收账款管理，降低坏账风险
  • 优化资产结构，提高资产质量
  • 建立资产盘活机制

八、投资建议与结论

8.1 九江市整体评估

优势：

1. 区位优势突出，交通基础设施完善

2. 经济总量大，产业结构合理，工业基础雄厚

3. 财政实力较强，一般公共预算收入稳居江西省前三位

4. 城投公司数量多，融资渠道畅通，融资成本持续改善

5. 区县经济发展相对均衡，开发区发展水平较高

挑战：

1. 经济增长面临放缓压力，受宏观经济波动影响较大

2. 房地产行业下行对政府性基金收入影响明显

3. 债务规模持续增长，广义债务率上升

4. 部分区县财政收入相对GDP规模偏低

综合评级：

九江市整体信用状况良好，经济财政基础扎实，债务压力适中，适合中长期投资。

8.2 德安县整体评估

优势：

1. 经济基础良好，财政自给能力较强

2. 产业定位清晰，智能制造示范区建设稳步推进

3. 德安城发作为重要基础设施建设主体，业务专营性强

4. 省级担保机构提供强担保，信用等级高

挑战：

1. GDP规模相对较小，2024年有所下降

2. 政府性基金收入受房地产行业影响下降明显

3. 项目投资规模大，面临资本支出压力

综合评级：

德安县经济财政状况良好，发展前景稳定，适合中长期投资。

8.3 德安城发投资建议

投资亮点：

1. 信用等级高

主体信用等级AA，评级展望稳定

债项信用等级AAA，由省级担保机构提供担保

担保机构信用等级AAA，担保能力强

2. 区域经济支撑

九江市经济实力强，德安县经济基础良好

基础设施建设需求持续存在

得到政府及股东支持

3. 业务专营性强

作为德安县重要基础设施建设主体，业务具有区域垄断性

在建及拟建项目规模大，未来收入有保障

投资风险：

1. 短期偿债压力

短期债务占比较高

资产流动性较弱

2. 盈利能力下降

受子公司划出影响，营业收入下降

基础设施建设业务毛利率较低

3. 项目投资压力

在建及拟建项目尚需投资规模大

资金来源需要合理安排

投资建议：

1. 债券投资

AAA级债项信用等级，省级担保增信，违约风险低

适合追求稳定收益的投资者

建议关注债券期限结构，分散投资

2. 投资策略

优先投资短期债券，降低流动性风险

关注项目进度和资金到位情况

监测德安县财政状况和信用变化

3. 风险控制

建立投资额度控制机制

定期评估投资组合风险

关注德安城发财务指标变化

术语说明

  • 一般公共预算收入：地方政府财政收入的主体部分，主要包括税收收入和非税收入
  • 政府性基金收入：地方政府通过征收或出让国有资产、资源等取得的收入
  • 财政自给率：一般公共预算收入/一般公共预算支出，反映财政自给能力
  • 广义债务率：（政府债务+城投债务）/综合财力，反映区域债务压力
  • 现金短期债务比：现金及现金等价物/短期债务，反映短期偿债能力
