2. The Core Innovation: Manifold-Constrained Hyper-Connections

2.1 Problem Diagnosis

The research team identified the root cause of HC instability:

1. Unconstrained Residual Mapping: Leads to unbounded signal amplification/attenuation

2. Signal Divergence: Composite mapping fails to preserve global mean of features

3. Restricted Scalability: Instability prevents effective large-scale training

2.2 Solution: Doubly Stochastic Manifold Projection

mHC projects the residual connection space onto the Birkhoff polytope- the set of all doubly stochastic matrices. A matrix H is doubly stochastic if:

  • All entries are non-negative: Hij ≥ 0
  • Each row sums to 1: Σj Hij = 1
  • Each column sums to 1: Σi Hij = 1

Key Properties:

  • Preserves L1 norm sum of values
  • Creates convex combination of features
  • Bounded eigenvalues stable dynamics

4. The Sinkhorn-Knopp Algorithm

4.1 Algorithm Overview

The Sinkhorn-Knopp algorithm is an iterative method that projects matrices onto the Birkhoff polytope doubly stochastic matrices. The algorithm:

1. Exponent: Make all elements positive via exponentiation

2. Iterate: Alternately normalize rows and columns to sum to 1

3. Converge: Repeat until convergence typically 5-20 iterations

4.2 Convergence Analysis

The convergence plot shows rapid reduction in row and column sum errors. The mHC implementation uses tmax = 20 iterations, achieving excellent convergence within this budget.

4.3 Why Sinkhorn-Knopp Works

Mathematical Properties:

  • Guaranteed convergence for positive matrices
  • Converges to the unique doubly stochastic matrix
  • Bounded eigenvalues ensure stable signal propagation
  • Computational complexity: On² × tmax where tmax is iterations

Practical Benefits:

  • Preserves signal energy norm preservation
  • Ensures compositional closure
  • Prevents signal amplification/attenuation
  • Enables stable large-scale training
