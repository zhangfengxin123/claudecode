华福化工周度精品数据库分析报告

执行摘要

本周（2026.1.12-2026.1.16），中国化工行业呈现出明显的分化走势。涤纶长丝产业链表现最为亮眼，三大产品POY、FDY、DTY全线上涨，平均涨幅达2.1%；硅化工产业链受益于光伏需求，有机硅DMC、三氯氢硅等产品价格稳步上扬；轮胎产业链在开工率回升的带动下，天然乳胶价格上涨2.61%。相比之下，聚氨酯产业链承压明显，聚合MDI、纯MDI、TDI全线下挫；纯碱产业链因开工率提升至88.7%，价格下跌0.58%。

整体来看，本周化工市场呈现出"光伏相关产业链走强，传统化工品承压"的结构性特征。下游光伏玻璃需求回暖、轮胎出口放缓、春节前备货预期等多重因素交织，使得各产业链走势分化加剧。

本周涤纶长丝三大产品全线上涨，POY价格6750元/吨（+2.7%）、FDY价格6925元/吨（+2.6%）、DTY价格7850元/吨（+1.0%）。价格上涨的主要原因：

六、市场趋势展望

6.1 短期展望（1-2周）

1. 涤纶长丝：春节临近，下游织造企业陆续放假，需求可能进一步走弱，价格或承压

2. 硅化工：光伏订单持续，需求有望保持稳定，价格或维持震荡偏强

3. 磷化工：春耕备货预期增强，价格有望获得支撑，但需关注实际需求跟进

4. 纯碱：开工率高位，供应压力持续，价格或继续承压

5. 聚氨酯：传统淡季，需求疲软，价格或维持弱势

6. 轮胎：出口放缓，季节性淡季，开工率或见顶回落

6.2 中期展望（1-3个月）

1. 光伏相关产业链：随着光伏装机旺季到来，硅化工、纯碱（光伏玻璃）需求有望持续改善

2. 农用化工：春耕备货旺季，磷化工、钾化工等农用化工品需求有望释放

3. 汽车相关：随着汽车市场复苏，轮胎、聚氨酯等汽车相关化工品需求有望改善

4. 原油相关：原油价格波动仍将影响炼化产业链，需密切关注国际原油走势

5. 房地产相关：房地产政策调整可能影响纯碱（浮法玻璃）、PVC等地产相关化工品需求

6.3 关键风险因素

1. 原油价格波动：国际原油价格大幅波动将直接影响炼化、化纤等产业链

2. 光伏政策变化：光伏产业政策调整可能影响硅化工、纯碱等产业链需求

3. 环保政策：环保检查可能影响部分化工品供应

4. 春节因素：春节前后工厂停工放假可能影响短期供需格局

5. 宏观经济：宏观经济走势将影响化工品整体需求

七、投资建议

7.1 看好板块

1. 光伏相关化工：硅化工（有机硅DMC、三氯氢硅）、纯碱（光伏玻璃）

2. 农用化工：磷化工（磷酸一铵、磷酸二铵）

3. 高端新材料：EVA、PA66等特种塑料

7.2 谨慎板块

1. 传统大宗化工：纯碱、MDI、TDI等供应过剩产品

2. 房地产相关：PVC、纯碱（浮法玻璃）等地产相关产品

3. 季节性疲软：聚氨酯、轮胎等季节性淡季产品

7.3 关注点

1. 春耕备货进度：关注磷化工、钾化工等农用化工品备货情况

2. 光伏装机数据：关注光伏装机数据和组件企业开工率

3. 原油价格走势：密切关注国际原油价格走势

4. 政策变化：关注环保、出口退税等政策变化

八、结论

本周化工行业呈现出明显的结构性分化特征。光伏相关产业链（硅化工、纯碱光伏玻璃）和农用化工（磷化工）表现较好，而传统大宗化工（聚氨酯、纯碱）承压明显。

从产业链层面看，涤纶长丝产业链和硅化工产业链是本周的明星板块，主要受益于库存去化和光伏需求。从产品层面看，三氯氢硅、POY、天然乳胶、FDY等产品涨幅居前，而顺丁橡胶、重质纯碱、磷酸二铵等产品跌幅居前。

展望未来，随着春耕备货和光伏装机旺季的到来，磷化工和硅化工产业链有望持续受益。但聚氨酯和纯碱产业链短期内仍面临供应压力和需求疲软的双重挑战。

总体而言，建议投资者关注光伏相关化工和农用化工等景气度较高的板块，谨慎对待传统大宗化工等产能过剩的行业。
