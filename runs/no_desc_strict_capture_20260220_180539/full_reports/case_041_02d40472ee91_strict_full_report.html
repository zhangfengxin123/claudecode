Executive Summary

This report presents a comprehensive analysis of monthly price data spanning January 2005 to December 2025, covering eight major asset classes: Chinese equity indices CSI800, HS300, US equity index S&P 500, precious metals Gold, industrial metals Copper, energy commodities Oil, and bonds STBOND, BOND10Y.

Key Findings:

  • Gold delivered the best risk-adjusted returnswith a Sharpe ratio of 0.660, balancing strong 12.12% annualized returns with moderate 15.33% volatility

  • Correlation analysis revealed distinct asset classes, with Chinese stocks showing moderate correlation 0.30-0.40 with US markets, providing some diversification benefits

Analytical Approach

The analysis employed the following methodology:

1. Data Cleaning: Removed null values, parsed dates, standardized column names

2. Return Calculation: Computed monthly returns using the formula: Rt = Pt / P{t-1} - 1

3. Risk Metrics: Calculated annualized volatility using monthly standard deviation × sqrt12

4. Performance Metrics: Computed Sharpe ratios assuming 2% risk-free rate, maximum drawdowns, and total returns

5. Visualization: Created multiple interactive charts to illustrate patterns and insights
