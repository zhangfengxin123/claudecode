中国银行业存款流出深度分析

执行摘要

中国银行业在2026年将面临前所未有的存款到期高峰。UBS研究报告显示，约55-60万亿人民币的存款将在2026年到期，占银行系统总存款的18%。这一现象源于2020-25年疫情期间家庭积累的超额储蓄（约8万亿人民币），以及房地产市场的持续低迷导致资金向存款转移。尽管市场担忧存款大规模流出，但分析显示超过90%的到期存款预计将继续留在银行系统内，仅有2-4万亿可能流向其他金融投资产品。总体而言，这对银行业而言是净正面影响，融资成本预计下降约14个基点。

一、背景：超额储蓄的积累

1.1 疫情期间储蓄率上升

新冠疫情（2020-22年）对中国家庭部门造成重大冲击，消费受到的影响远超收入。尽管2023-25年家庭消费情绪保持谨慎，导致过去6年的家庭储蓄率高于疫情前正常水平。

1.2 存款大幅增长

与此同时，中国家庭存款在过去几年出现显著"额外增长"：

  • 2022-23年：每年超过17万亿（显著高于2019-21年的10万亿/年）
  • 2024-25年：约14.5万亿/年（仍处于历史高位）

这一现象与超额储蓄规模相关，但并非完全等同。其他促成因素包括：

1. 监管收紧：2022-23年理财产品、公募基金和股票市场投资回报大幅下降

2. 房地产市场低迷：住宅销售额从2021年16万亿峰值降至2025年7.3万亿

3. 抵押贷款收缩：2023-25年抵押贷款持续收缩

4. 相对高利率：2022-23年银行提供相对较高且稳定的定期存款利率（如3-5年期2.5-2.75%）

二、2026年：存款到期高峰

2.1 到期规模

基于7家主要银行（6大国企银行+招商银行）的到期披露信息（持有约160万亿存款，占系统约50%），通过将1-5年期存款按年度细分分析，我们估计：

  • 2026年到期存款：约55-60万亿人民币
  • 占总存款比例：约18%
  • 主要结构：1-3年期定期存款（2022-23年最受欢迎产品）

利率大幅下降导致2026年面临最大的存款流出压力，因为大部分高利率存款需要重定价为当前水平。

三、资金流向预测

3.1 总体流向

与主要银行的讨论显示，超过90%的到期存款将继续存入新的定期存款。其余部分（约2-4万亿）可能配置到其他金融投资产品。

四、对银行业的影响

4.1 正面影响

存款到期波浪将对银行产生净正面影响：

1. 融资成本下降：高利率存款重定价将降低整体融资成本约14个基点

长期定期存款平均利率下降90基点

存款成本下降20基点

整体融资成本降低14基点

2. 手续费收入增加：向投资产品迁移将支持手续费收入增长

部分流出零售存款的资金最终以非银行金融机构存款或其他形式返回银行系统

代销理财产品、基金等将带来中间业务收入

3. 净息差改善：存款重定价应能支撑净息差

4.2 风险与挑战

尽管基本面支持存款重定价，但仍需关注以下风险：

1. 流动性风险：特别是存贷比较高或流动性较紧张的银行

2. 资产质量恶化：受宏观经济环境和国内房地产市场活动疲软影响

3. 资本充足性风险：与再融资相关的稀释风险

4. 利率下行风险：对银行盈利能力的压力

七、结论与展望

7.1 核心发现

1. 2026年是到期高峰：55-60万亿存款到期，占总存款18%

2. 大规模流出风险有限：超过90%预计继续留在银行系统

3. 资金再配置有序：仅2-4万亿流向其他金融产品

4. 银行业整体受益：融资成本下降14bps，手续费收入增加

7.2 市场影响

尽管存款到期应该对银行业是净正面，支持净息差和手续费收入，但我们预计这不会转化为净利润增长的显著升级。因此，在牛市中，中国银行股可能仍会落后，因为该行业的利润前景仍然温和。

中国银行股年初至今已经跑输大盘。这种表现落后主要由以下因素造成：

  • 板块轮换
  • 与国家队指数ETF减持相关的抛售压力
  • 万科债券重组后对不良贷款风险的担忧重新升温

即使存款重定价提供支撑性基本面，如果整体资本市场保持强劲，银行股可能仍然表现滞后。

7.3 投资建议

从中期来看，UBS仍看好以下银行：

  • 高股息率银行：中信银行H股、建设银行H股、工商银行H股
  • 快速增长高ROE银行：宁波银行、北京银行

7.4 后续关注重点

1. 2026年实际流出数据：监测实际流出规模是否符合2-4万亿预期

2. 利率走势：未来是否进一步降息影响存款吸引力

3. 宏观经济环境：经济复苏和房地产市场对居民风险偏好的影响

4. 资本市场表现：股票市场表现对资金流向投资产品的吸引力
