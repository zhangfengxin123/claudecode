3.2 订单量与GMV的相关性

订单量与GMV的相关系数为 0.98，呈极强正相关。这说明订单量是GMV的主要驱动力。

但是，不同品牌的客单价差异导致相同订单量带来的GMV差异巨大：

这意味着，虽然蜜雪冰城的订单量是瑞幸的5.2倍，但由于客单价仅为1/6，GMV反而略低。
