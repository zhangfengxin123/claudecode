### **2026 MCM 题目 C：与星共舞的数据 (Data With The Stars)**

《与星共舞》（Dancing with the Stars, DWTS）是一档基于英国节目《严格来跳舞》（Strictly Come Dancing）的国际电视特许经营节目的美国版。该节目的版本已出现在阿尔巴尼亚、阿根廷、澳大利亚、中国、法国、印度等许多国家。作为本题焦点的美国版，目前已完成了34季。

名人们与专业舞者搭档，每周表演舞蹈。专家评审团会对每一对组合的舞蹈进行打分，粉丝们则（通过电话或网络）投票选出他们当周最喜欢的一对。粉丝可以投一票或多票，但不能超过每周公布的上限。此外，粉丝投票是为了留住他们希望留下的明星，而不能投票淘汰某位明星。评委分数和粉丝投票将结合起来，以决定当周淘汰哪一对组合（综合得分最低者）。有三对（某些季度更多）组合会进入总决赛，在决赛周，粉丝和评委的综合得分将用于对他们进行第1名至第3名（或第4、第5名）的排名。

将粉丝投票和评委分数结合的方法有很多种。在美国版的前两季中，这种结合是基于**排名（Ranks）**的。第2季出现的问题（名人选手 Jerry Rice 尽管评委打分很低却进入了决赛）导致节目组修改了规则，使用**百分比（Percentages）**代替排名。附录中提供了这两种方法的示例。

在第27季，当名人选手 Bobby Bones 尽管评委打分持续低迷却最终夺冠时，引发了另一次“争议”。作为回应，从第28季开始，淘汰流程做了一点微调。通过结合评委分数和粉丝投票确定排名垫底的两名选手，然后在直播节目中，由评委投票决定淘汰这两名中的哪一位。大约在这个赛季，制作人也恢复了使用**排名法**来结合评委分数与粉丝投票（就像第1季和第2季那样）。虽然确切的变更赛季未知，但有理由假设是在第28季。

评委的分数旨在反映哪些舞者在技术上更好，尽管对于什么样的舞蹈更好存在一定的主观性。粉丝的投票可能更加主观，受舞蹈质量影响，但也受名人的受欢迎程度和个人魅力的影响。节目制作人可能实际上在某种程度上更喜欢意见和投票上的冲突，因为这种情况能提升粉丝的兴趣和兴奋度。

### **任务要求**

题目提供了包含评委分数和选手信息的数据，描述如下。你可以自行决定是否包含额外信息或其他数据，但必须完全注明来源。请利用这些数据完成以下任务：

1.  **建立数学模型（或多个模型），为每位选手在其参赛的各周估算粉丝投票数（这是未知的，且被视为严守的秘密）。**
    *   你的模型估算的粉丝票数是否能得出与每周实际淘汰结果一致的结论？请提供一致性的衡量标准。
    *   你得出的粉丝票数总量的确定性（certainty）如何？对于每位选手/每一周，这种确定性是否总是相同的？请提供你估算值的确定性度量。

2.  **利用你的粉丝票数估算值配合其余数据进行分析：**
    *   比较和对比节目组用于结合评委和粉丝投票的两种方法（即**排名制**和**百分比制**）在不同赛季的表现（即对每个赛季都应用这两种方法）。如果结果存在差异，某种方法是否看起来比另一种更偏向粉丝投票？
    *   检查这就两种投票方法在特定名人身上的应用，特别是那些存在“争议”（即评委和粉丝意见分歧）的案例。如果改变结合评委分数和粉丝投票的方法，这些选手的比赛结果会一样吗？如果加入“评委从倒数两名中选择淘汰谁”这一额外机制，会如何影响结果？
        *   你可以考虑的一些例子（你也可能发现其他例子）：
            *   第2季 —— Jerry Rice，尽管在5周中评委评分最低，却获得了亚军。
            *   第4季 —— Billy Ray Cyrus，尽管在6周中评委评分倒数第一，却获得了第5名。
            *   第11季 —— Bristol Palin，尽管12次评委评分最低，却获得了第3名。
            *   第27季 —— Bobby Bones，尽管评委评分持续低迷，却赢得了冠军。
    *   基于你的分析，你会建议在未来的赛季中使用哪种方法？为什么？你会建议保留“评委从倒数两名中选择”这一额外机制吗？

3.  **利用数据（包括你估算的粉丝票数）建立一个模型，分析不同的专业舞者以及数据中提供的名人特征（年龄、行业等）的影响。**
    *   这些因素在多大程度上影响名人在比赛中的表现？
    *   它们对评委打分和粉丝投票的影响方式相同吗？

4.  **提出另一种利用每周粉丝投票和评委分数的系统。**
    *   你认为该系统更“公平”（或者在其他方面“更好”，例如让节目对粉丝来说更刺激）。请提供支持理由，说明为什么节目制作人应该采纳你的方法。

5.  **撰写一份不超过25页的报告陈述你的发现，并包含一份1到2页的备忘录。**
    *   备忘录应总结你的结果，并就评委分数与粉丝投票的结合方式对《与星共舞》制作人提出建议，指导未来的赛季该如何操作。

### **数据说明**

**数据文件：** `2026_MCM_Problem_C_Data.csv` —— 包含第1至34季的选手信息、结果和每周评委分数。数据描述见表1。

**表1：2026_MCM_Problem_C_Data.csv 数据描述**

| 变量名 | 解释 | 示例 |
| :--- | :--- | :--- |
| `celebrity_name` | 名人选手姓名（明星） | Jerry Rice, Mark Cuban, … |
| `ballroom_partner` | 专业舞伴姓名 | Cheryl Burke, Derek Hough, … |
| `celebrity_industry` | 明星职业类别 | 运动员 (Athlete), 模特 (Model), … |
| `celebrity_homestate` | 明星家乡州（如果是美国人） | Ohio, Maine, … |
| `celebrity_homecountry/region` | 明星家乡国家/地区 | United States, England, … |
| `celebrity_age_during_season` | 赛季期间明星的年龄 | 32, 29, … |
| `season` | 节目季数 | 1, 2, 3, …, 32 |
| `results` | 赛季结果 | 第1名 (1st Place), 第2周淘汰 (Eliminated Week 2), … |
| `placement` | 赛季最终名次（1为最好） | 1, 2, 3, … |
| `weekX_judgeY_score` | 第X周评委Y的打分 | 1, 2, 3, … |

**数据注意事项：**

1.  每个舞蹈的评委打分从 1（低）到 10（高）。
    *   a. 在某些周，报告的分数包含小数（例如 8.5），因为每位名人表演了不止一支舞蹈，分数是平均后的结果。
    *   b. 在某些周，给予了加分（斗舞环节等）；这些分数被平均分摊到评委/舞蹈分数中。
    *   c. 团体舞分数是与每位团队成员的个人分数平均计算的。
2.  评委按打分顺序列出；因此“评委Y”在不同周或不同赛季可能不是同一位评委。
3.  不同赛季的名人数量不同，节目播出的周数也不同。
4.  第15季是唯一一季由回归明星组成的全明星阵容。
5.  偶尔会出现某周没有名人被淘汰，或者某周有一名以上名人被淘汰的情况。
6.  数据集中会出现 `N/A` 值，情况如下：
    *   a. 第4位评委的分数，如果该周没有第4位评委（通常只有3位）。
    *   b. 节目在某季未播出的周数（例如，第1季持续了6周，因此第7至11周记录为N/A值）。
7.  被淘汰的名人记录为0分。例如，在第1季，第一位被淘汰的名人是 Trista Sutter（在第2周节目结束时）。因此她在本季剩余时间（第3周至第6周）的分数为0。

### **附录：投票方案示例**

**1. 基于排名的结合 (COMBINED BY RANK) - 用于第1、2季及28-34季(a)**
在第1季和第2季，评委和粉丝的投票是通过**排名**结合的。例如，在第1季第4周，剩下四名参赛者。Rachel Hunter 被淘汰，意味着她的综合排名最低（注：此处通常指排名数字最大，即最差）。在表2中显示了评委分数和排名，我们要创建一个可能的粉丝投票集来产生正确的结果。有许多可能的粉丝投票值可以得出相同的结果。你不应使用这些作为实际值，因为这只是一个例子。由于 Rachel 被评委排在第2名，为了以最低的综合得分（最差结果）结束，她的粉丝投票必须是最低的（第4名），总排名为6。

**表2：基于排名的结合示例（第1季，第4周）**
| 选手 | 评委总分 | 评委排名 | 粉丝票数* | 粉丝排名* | 排名总和 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Rachel Hunter | 25 | 2 | 110万 | 4 | 6 |
| Joey McIntyre | 20 | 4 | 370万 | 1 | 5 |
| John O’Hurley | 21 | 3 | 320万 | 2 | 5 |
| Kelly Monaco | 26 | 1 | 200万 | 3 | 4 |
*\*粉丝票数/排名未知，假设值是为了产生正确的最终排名而选取的。*

**2. 基于百分比的结合 (COMBINED BY PERCENT) - 用于第3季至第27季(a)**
从第3季开始，分数使用**百分比**而不是排名来结合。以第5季第9周为例。在那一周，Jennie Garth 被淘汰。同样，我们人为创建了粉丝票数，得出总百分比以正确导致该结果。评委百分比的计算方法是：该选手的评委总分除以所有4名选手的评委总分之和。根据评委百分比，Jennie 是第3名。然而，加上我们分配给她的1000万张人为粉丝票的百分比后，她是第4名。

**表3：基于百分比的结合示例（第5季，第9周）**
| 选手 | 评委总分 | 评委百分比 | 粉丝票数* | 粉丝百分比* | 百分比总和 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Jennie Garth | 29 | 29/117 = 24.8% | 110万 | 1.1/10 = 11% | 35.8 |
| Marie Osmond | 28 | 28/117 = 23.9% | 370万 | 3.7/10 = 37% | 60.9 |
| Mel B | 30 | 30/117 = 25.6% | 320万 | 3.2/10 = 32% | 57.8 |
| Helio Castroneves | 30 | 30/117 = 25.6% | 200万 | 2/10 = 20% | 45.6 |
| **总计** | **117** | | **1000万** | | |
*\*粉丝票数未知，假设值是为了产生正确的最终排名而选取的。*

*(a) 恢复排名制的确切年份尚不确定；第28季是一个合理的假设。*
