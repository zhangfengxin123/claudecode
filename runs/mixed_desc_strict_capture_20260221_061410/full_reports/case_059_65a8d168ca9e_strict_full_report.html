执行摘要

本报告对2025年5月至8月期间的广告投放数据进行了深入分析，排除异常值和通过率因素后，识别出4个明显的CPS周期性上涨阶段。研究发现，CPI成本上升、CTR下降以及消耗增加是导致CPS上涨的三大核心驱动因素，而非通过率变化。通过率在CPS上涨期间反而略有下降或保持稳定，说明通过率并非CPS波动的主要原因。

关键发现：

  • 识别出4个CPS上涨阶段，最高涨幅达164.3%
  • CPI成本上升是CPS上涨的最主要驱动因素（最高上升156.4%）
  • CTR下降导致获客成本上升（最高下降61.5%）
  • 通过率在上涨期间保持稳定或略有下降，非主导因素

1.2 数据清洗方法

异常值识别（IQR方法）：

  • 正常CPS范围：1.4 - 29.1元
  • 异常值阈值：< -5.18 或 33.43元
  • 异常值特点：通常伴随极低的通过率（< 2.6%）

排除的异常值示例：

  • 2025-07-31：CPS = 273.6元，通过率 = 0.5%
  • 2025-08-03：CPS = 145.4元，通过率 = 0.9%
  • 2025-06-20：CPS = 105.5元，通过率 = 0.7%

这些异常值主要是由于数据质量问题或特殊情况导致的极端值，不反映正常的业务趋势，因此予以排除。

1.3 分析方法

CPS上涨阶段识别标准：

1. 7日移动平均线持续上升

2. 连续3天或更多天呈上升趋势

3. 排除通过率大幅波动的影响

驱动因素分析方法：

  • 对比阶段前7天与阶段内的各项指标变化
  • 计算各因素的变化幅度和相关系数
  • 识别对CPS影响最显著的驱动因素

12. 战略建议

12.1 短期优化措施

1. 降低CPI成本

  • 优化广告素材，提高点击率和转化率
  • 精细化定向，提高广告投放精准度
  • A/B测试不同广告文案和创意

2. 提高CTR

  • 优化广告创意和标题
  • 改进着陆页体验
  • 增加广告素材的吸引力

3. 控制消耗节奏

  • 合理分配预算，避免集中投放导致竞争加剧
  • 优化出价策略，避免竞价过高

12.2 中长期战略建议

1. 提升转化漏斗效率

  • 优化注册流程，提高注册率
  • 改进申贷流程，提高申贷率
  • 加强风控审核，提高通过率（虽然目前不是主要问题）

2. 提升用户质量

  • 优化定向策略，精准触达目标用户
  • 改进产品体验，提高用户留存和转化
  • 建立用户分层运营体系

3. 建立CPS监控机制

  • 实时监控CPI、CTR等关键指标
  • 设置阈值预警，及时发现问题
  • 定期分析CPS上涨原因，快速响应

12.3 数据驱动优化

1. 建立归因分析模型

  • 追踪用户从点击到放款的完整路径
  • 识别转化漏斗中的关键瓶颈
  • 定位CPI上升的具体原因

2. 优化投放策略

  • 基于历史数据优化投放时段
  • 根据用户画像优化定向策略
  • 动态调整出价，平衡成本和效果

3. 建立预测模型

  • 预测CPS趋势，提前做好预算规划
  • 预警CPI和CTR异常波动
  • 优化资源分配，提高ROI

13. 结论

13.1 核心发现

通过对2025年5月至8月期间的广告投放数据进行深入分析，我们识别出4个明显的CPS周期性上涨阶段。排除异常值和通过率因素后，研究发现：

1. CPI成本上升是CPS上涨的最主要驱动因素

最高上升156.4%（阶段1）

平均上升幅度显著

2. CTR下降导致获客成本上升

最高下降61.5%（阶段1）

与CPI上升形成恶性循环

3. 消耗增加推动CPS上涨

最高增加461.3%（阶段1）

预算投入力度加大

4. 通过率不是CPS上涨的原因

在所有上涨阶段中，通过率均下降或保持稳定

说明通过率与CPS上涨无直接关联

5. 转化率下降（注册率×申贷率）也是重要因素

导致放款量减少，从而推高CPS

13.2 行动建议

立即执行（1-2周）：

  • 优化广告素材，提高CTR
  • 调整出价策略，降低CPI
  • 建立CPS监控预警机制

短期优化（1个月）：

  • 优化注册和申贷流程，提高转化率
  • 精细化定向，提高用户质量
  • 建立归因分析模型

中长期战略（3-6个月）：

  • 建立预测模型，提前预警
  • 优化投放策略，提高ROI
  • 建立数据驱动的优化体系

13.3 预期效果

通过实施上述优化措施，预期可以达到以下效果：

  • CPI降低20-30%
  • CTR提高15-25%
  • 注册率提高5-10%
  • 申贷率提高5-10%
  • CPS稳定在10-15元区间

  • 使用IQR方法识别异常值
