执行摘要

本报告基于混淆矩阵完整分析数据，对订单标签预测模型进行了全面的性能评估。模型在总共 32,465条业务数据上展现出优异的性能表现：

  • 准确率: 98.85%
  • 召回率: 98.90%
  • 精确率: 99.36%
  • F1 Score: 99.13%

尽管整体性能优秀，但通过深入分析发现 Type II 错误 FN的绝对数量（236例）是 Type I 错误 FP的1.7倍，需要优先关注和优化。

9. 结论

9.1 总结

本分析报告对订单标签预测模型进行了全面评估，得出以下核心结论：

1. 模型整体性能优异: 98.85%的准确率、98.90%的召回率、99.36%的精确率表明模型在大多数情况下表现卓越
