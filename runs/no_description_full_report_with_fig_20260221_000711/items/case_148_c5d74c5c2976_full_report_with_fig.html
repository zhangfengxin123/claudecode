Reinforcement Learning with Verifiable Rewards: A Critical Analysis of Reasoning Capacity in LLMs

Executive Summary

This analysis examines a groundbreaking research paper from Tsinghua University and Shanghai Jiao Tong University that challenges conventional wisdom about Reinforcement Learning with Verifiable Rewards RLVR in Large Language Models. The study systematically probes RLVR's effectiveness across multiple model families, algorithms, and benchmarks, revealing a surprising finding: current RLVR methods do not fundamentally expand reasoning capabilities beyond base models.

Key insights:

  • RLVR improves sampling efficiency but narrows reasoning coverage
  • Base models outperform RLVR models when allowed multiple attempts large k values
  • All tested RL algorithms show similar suboptimal performance
  • Distillation, not RLVR, genuinely expands reasoning capabilities

The RLVR Paradigm

Reinforcement Learning with Verifiable Rewards has emerged as a dominant approach for enhancing LLM reasoning capabilities, particularly in mathematics and coding tasks. Models like OpenAI-o1, DeepSeek-R1, and Kimi-1.5 have demonstrated remarkable performance improvements through RLVR training.

The fundamental premise behind RLVR is simple yet powerful: use automatically computable rewards e.g., correct mathematical solutions, passing unit tests to guide model improvement without human labeling. This mirrors traditional RL successes in game playing Atari, Go where agents discover novel strategies through exploration.

The Critical Question

Despite RLVR's empirical success, the authors raise a fundamental question:

"Does current RLVR genuinely enable LLMs to acquire novel reasoning abilities—similar to how traditional RL discovers new strategies through exploration—or does it simply utilize reasoning patterns already in the base model?"

Novel Evaluation Approach

Unlike traditional evaluations that rely on average scores from greedy decoding or nucleus sampling, this study adopts the pass@k metricwhere a problem is considered solved if ANY of k sampled outputs is correct. This reveals the model's potential to solve problems, not just its average-case performance.

Key Finding 1: RLVR Narrows Reasoning Coverage

The Fundamental Pattern

Across all benchmarks and model sizes, a consistent pattern emerges:

  • Small k k=1, 5, 10: RLVR models consistently outperform base models
  • Large k k=100, 200, 256: Base models consistently surpass RLVR models

This crossover is not just a statistical artifact—it reveals a fundamental trade-off in RLVR training.

Interpretation

This pattern suggests:

1. RLVR increases efficiencyon problems already solvable by the base model

2. RLVR reduces coverageby eliminating some correct reasoning paths

3. Base models have broader potentialdespite lower average performance

Fundamental Limitation Identified

The study reveals that current RLVR methods:

1. Do not discover fundamentally new reasoning patterns

2. Simply bias distribution toward rewarded paths

3. Remain bounded by base model capabilities

4. Trade exploration for efficiency

RLVR vs Distillation

A critical comparison emerges:

ApproachMechanismEffect on ReasoningOutcome
RLVROptimization on base distributionImproves efficiency on existing pathsBounded by base model
DistillationTransfer from teacherIntroduces new reasoning patternsCan exceed base model

Distillation can genuinely expand reasoning capabilities by transferring novel patterns from a teacher model, while RLVR is constrained within the base model's distribution.

Technical Deep Dive: Understanding the Mechanism

分析问题
  • Why does RLVR narrow reasoning coverage?
  • What is the theoretical explanation for the observed patterns?

Reward Optimization Hypothesis

The key mechanism is reward-driven optimization without exploration:

1. Initial state: Base model has diverse reasoning paths

2. RL training: Model optimizes for correct answers

3. Concentration: Probability mass shifts to rewarded paths

4. Side effect: Some correct paths with lower initial probability get eliminated

Mathematical Intuition

Without exploration, the optimization converges to:

  • High-reward paths that were already in Pbase
  • Low-probability paths even if correct get suppressed

Perplexity Analysis Confirmation

The study's perplexity analysis confirms this:

  • RLVR-generated reasoning paths exist in base model distribution
  • Low perplexity indicates paths are not novel
  • Base model can generate these paths just with lower probability

Practical Implications for Practitioners

分析问题
  • How should practitioners use RLVR given these findings?
  • When is RLVR appropriate vs when is distillation better?

When to Use RLVR

Use RLVR when:

  • Goal is improving average performancepass@1
  • You need consistent correct outputswith fewer samples
  • Efficiencyis more important than exploration
  • Base model already has good reasoning coverage

Example applications:

  • Production systems with limited sampling budget
  • Automated grading systems
  • Customer support chatbots
  • Code generation for common patterns

When to Use Distillation

Use distillation when:

  • Goal is expanding reasoning capabilities
  • You have access to a stronger teacher model
  • Coverageis more important than efficiency
  • Base model has limited reasoning patterns

Example applications:

  • Building specialized domain models
  • Transfer learning across domains
  • Creating smaller models from larger ones
  • Bootstrapping new capabilities

Hybrid Approach Considerations

The study suggests a two-stage approach:

1. Distillation first: Expand reasoning capabilities from teacher

2. RLVR second: Optimize efficiency on expanded capabilities

This could potentially achieve both coverage and efficiency gains.

Conclusion

分析问题
  • What is the main takeaway from this analysis?
  • How does this reshape our understanding of RLVR in LLMs?

Key Takeaway

Current RLVR methods do not fundamentally expand reasoning capabilities beyond base models.Instead, they improve sampling efficiency on problems the base model can already solve, at the cost of reducing overall reasoning coverage.

Paradigm Shift

This finding represents a significant paradigm shift in our understanding of RLVR:

Old view:

  • RLVR = continuous self-improvement
  • Discovers novel reasoning strategies
  • Unbounded growth in capabilities

New view:

  • RLVR = efficiency optimization
  • Biases existing reasoning distribution
  • Bounded by base model capabilities

Path Forward

To unlock the true potential of RL in LLMs, we need:

1. Better exploration mechanisms

2. Process-level rewards

3. Multi-turn interactions

4. Integration with distillation

Final Thoughts

This study doesn't diminish RLVR's achievements—it provides a roadmap for moving forward. By understanding RLVR's limitations, we can design improved approaches that genuinely expand reasoning capabilities, bringing us closer to truly self-improving AI systems.

The key insight is elegant and profound: efficiency without exploration is optimization, not innovation.To achieve genuine reasoning breakthroughs, RLVR must embrace exploration, not just exploitation.
