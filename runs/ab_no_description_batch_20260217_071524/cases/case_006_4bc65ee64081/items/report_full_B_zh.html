茶饮业务组品牌下探数据分析报告

执行摘要

本报告对KA品牌下沉探索项目中的19个茶饮与咖啡品牌进行了全面分析，考察了其在2025年1月于GMV、广告效率、门店运营及增长趋势等关键指标上的表现。

核心发现

  • 市场规模：2025年1月，147,234家门店创造了10.4亿元GMV
  • 集中度：前三大品牌瑞幸咖啡、蜜雪冰城、COTTI COFFEE占总GMV的59.1%
  • 增长分化：11个品牌增长，6个品牌下滑——平均增长率为10.2%
  • 广告效率：行业平均每1元广告花费的CPC广告投资回报为13.08元
  • 表现差距：小型品牌（门店数≤5千）的单店GMV是大型品牌（门店数≥1万）的1.48倍

战略建议

For Large Brands

门店数≥1万家

挑战：规模导致与小型竞争对手相比效率存在差距

Recommendations:

1. 高端化：通过向上销售和高端产品线提升平均订单价值

2. 优化广告支出：借鉴瑞幸咖啡24.50元/1元的投资回报率模型

3. 门店绩效分析：识别表现不佳的门店以进行优化或关闭

4. 数字化转型：提升点击付费广告效率

For Medium Brands

5000-10000家门店

机遇：增长优化的最佳区间

Recommendations:

1. 规模化扩张：积极拓展门店以实现大型品牌规模经济

2. 广告投资：增加点击付费广告支出以抢占衰退大型品牌市场份额

3. 品牌差异化：运用COTTI COFFEE年同比增长47%的增长策略

4. 卓越运营：在扩张同时保持优异的单店总交易额效率

For Small Brands

5000家门店以下

优势：卓越的单店运营效率

Recommendations:

1. 聚焦高端：强化高价值定位——七鲜咖啡模式：单店28,085元

2. 战略扩张：在高潜力市场进行精准扩张

3. 数据驱动增长：投资客户数据分析以优化营销策略

4. 合作机遇：考虑与大型品牌建立战略合作或被收购

Conclusion

茶饮咖啡市场呈现明显两极分化：

  • 规模领导者：瑞幸咖啡与蜜雪冰城以45.9%市场份额占据主导
  • 增长领军者：COTTI COFFEE年增47%与书亦烧仙草总部年增59.6%颠覆市场格局
  • 高端参与者：星巴克与霸王茶姬保持高价值定位
  • 效率领先者：小型品牌在单店指标上表现突出

关键成功要素：

1. 扩大市场份额但不一定提升效率

2. 广告效率与投资回报率是关键竞争优势

3. 高端定位能实现更优的单店经济模型

4. 库迪咖啡的激进增长模式可能挑战行业领导者

市场仍高度动态，增长与整合机会并存。兼具规模优势、运营效率和智能广告策略的品牌将成为赢家。
