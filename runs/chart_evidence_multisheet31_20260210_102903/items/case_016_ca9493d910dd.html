# 实验信息
1. 组别：A 组为控制组，B1 组为最优价格实验组，B2 组为激进降价实验组，B3 组为反向涨价实验组
2. 实验周期：2026-01-23 至 2026-01-29 共 7 天
3. 实验目标：套餐定价模型效果评估。连续包月基线价格 25 元，模型判断连续包月 23 元为最优价格，验证激进降价到 19 元，以及激进涨价到 29 元的影响。
4. 实验干预：
    1. A 组，50% 流量，展示的套餐列表为：连续包月25元，年卡249元，连续包季98元，季卡128元，月卡50元
    2. B1 组，30% 流量，展示的套餐列表为：连续包月23元，年卡249元，连续包季98元，季卡128元，月卡50元
    3. B2 组，10% 流量，展示的套餐列表为：连续包月19元，年卡249元，连续包季98元，季卡128元，月卡50元
    4. B3 组，10% 流量，展示的套餐列表为：连续包月29元，年卡249元，连续包季98元，季卡128元，月卡50元
5. 实验预期：
    1. 预期 B1 组整体付费率大于 A 组，ARPU 与 A 组无显著差异
    2. 预期 B2 组整体付费率大于 B1 组，ARPU 小于 B1 组
    3. 预期 B3 组整体付费率小于 B1 组
5. 实验数据：
    1. 整体指标：实验期内的整体值，用于产生最终实验结果。其特点在于：例如一个设备多天活跃，在整体指标中只计算 1 次，而在日度指标中会计算多次
    2. 日度指标：实验期内的每日指标，用于辅助校验整体指标的效果
6. 数据分析目标：
    1. 核心目标：验证实验预期是否满足
    2. 次要目标：对每种套餐的付费率进行评估，量化蚕食效应的方向和大小

# 业务知识
1. 套餐类型
    1. 一年卡：会员权益时长为 1 年的套餐
    2. 两年卡：会员权益时长为 2 年的套餐
    3. 连续包月：会员权益时长为 1 个月的套餐，会自动续费
2. 用户进入收银台后，展示给用户的套餐通常是前 2 个或前 3 个
3. 价格锚点效应会影响用户决策。例如：假设用户愿意购买连续包月和年卡，年卡价格 249 平摊到单月价格为 20.75，由于 19 < 20.75 < 21，因此用户会更愿意购买 19 元的连续包月套餐
4. 存在“蚕食效应”，单套餐收入受其他套餐价格和顺序影响

# 指标计算口径
1. 付费率 = 付费订单数 / 活跃设备数
    1. 【套餐】付费率 = 【套餐】付费订单数 / 活跃设备数
2. ARPU = 付费金额 / 活跃设备数
3. ARPPU = 付费金额 / 付费订单数
