# Pardus 调研主手册（Playbook v1）

更新时间：2026-02-08  
适用阶段：产品调研早期（先证据、后设计）

## 1. 文档定位

- 这是一份“单文件主手册”，整合了：
  - 调研批次计划
  - Batch A 高价值输入队列
  - 安全执行策略
  - Run 记录模板与打分矩阵
  - 20 次后决策门槛
- 目标：避免文档分散，执行时只看这一份。

## 2. 调研原则

- 以证据链为中心：`原始数据 -> 分析过程 -> 图表资产 -> 文本结论 -> 复算校验`
- 不做纯凑次数 run，每次必须有新增信息目标。
- 不提前定最终产品边界，先通过 run 结果收敛边界。

## 3. 批次计划

### Batch A（20 次，功能摸底）

- 目标：确认默认分析链路、图表生成模式、常见结论结构。

### Batch B（20 次，可控性对照）

- 目标：验证同数据不同提示、同提示不同数据时的稳定性。

### Batch C（60~100 次，边界与失败模式）

- 目标：系统挖掘极限输入下的降级行为与失败模式。
- 说明：不是必须跑满 100；满足停止条件即可收敛。

## 5. 安全执行策略（反误判/反刷站）

- 单线程执行，不并发 run。
- 节奏限制：
  - run 间隔 3~7 分钟
  - 每小时 <= 4 次
  - 每日建议 <= 12 次
- 风险熔断（任一触发即停）：
  - 429
  - 强制验证码/登录异常
  - 连续 3 次 5xx
  - 页面持续 `Unknown error`
- 熔断后动作：
  - 记录触发点
  - 等待 30 分钟
  - 再触发则转人工介入

## 7. 打分矩阵标准

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 结果准确性 | 多处错误 | 核心大体对 | 关键指标复算一致 |
| 证据完整性 | 缺关键证据 | 基本齐全 | 证据链完整 |
| 可控性 | 漂移大 | 部分可控 | 方向稳定可控 |
| 可复现性 | 重跑差异大 | 主体稳定 | 高度稳定 |
| 失败可解释性 | 黑盒失败 | 部分可解释 | 失败原因清晰 |
| 输出可用性 | 难落地 | 可参考 | 可直接决策 |
| 交互效率 | 慢且不稳 | 可接受 | 快速稳定 |
| 鲁棒性 | 易崩/误导 | 可降级 | 稳定防呆 |

总分阈值：

- `>=30`：高质量 run
- `24~29`：可用 run
- `<24`：低质量 run（不计入有效样本）

## 8. 进入复刻设计的门槛（20 次后评审）

满足以下条件即可进入 MVP 范围定义：

1. 有效 run >= 20
2. 核心场景覆盖率 >= 80%
3. 关键指标复算一致率 >= 90%
4. 平均分 >= 28/40
5. 已沉淀：
   - Top10 高价值能力
   - Top10 失败模式
   - Top5 高风险边界

若任一不满足：补跑 10 次（补薄弱覆盖）后再评审。

## 9. 人工介入触发点（需要你出手）

- 登录或验证码。
- 配额不足或付费门槛。
- 你要调整优先级（如先医疗/先金融）。
