## Top Observations

- 强项：
  - 结构化业务数据（A01/A04/A07/A09）在“原始数据 -> 图表/表格”链路上可稳定复算。
  - 多源时序合并与相关性分析（A08）可做到数值级一致。
  - 同案例重放稳定（A02），说明公开链路具备一定确定性。
- 风险：
  - 特征级统计表在部分案例存在字段映射错误风险（A05/A06）。
  - 账单类案例存在隐式清洗和口径规则（A10），不显式会导致复现失败。
- 启示：
  - 复刻必须内置“可审计复算层（字段、过滤、聚合口径）”，而非只做文本总结与图表渲染。
