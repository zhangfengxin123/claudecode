## 字段定义

| 字段 | 说明 |
|---|---|
| failure_id | 唯一编号 |
| run_id | 来源 run |
| 触发条件 | 触发时的输入或操作 |
| 表现 | 页面/接口/输出异常表现 |
| 影响范围 | 结果准确性、可用性或稳定性影响 |
| 可复现性 | 高 / 中 / 低 |
| 临时规避方案 | 当前可用 workaround |
| 后续验证 | 下一步验证动作 |
